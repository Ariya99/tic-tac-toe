## 2024-05-18 - [Dynamic Turn Title and Interactive Cursors]
**Learning:** Adding `cursor="hand2"` in Tkinter Canvases greatly helps users understand they can interact with the element. Updating the window title dynamically is a non-intrusive way to surface current game state (e.g. whose turn it is or if it is Game Over) without cluttering the UI.
**Action:** Consistently add hover/cursor pointers to interactive canvas elements and consider using window titles or lightweight labels for important status messages.
