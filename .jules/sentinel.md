## 2026-10-30 - Prevent Array Out-of-Bounds Denial of Service from GUI Clicks
**Vulnerability:** The application converts Tkinter mouse click coordinates directly to NumPy array logical indices (`self.convert_grid_to_logical_position`) without validating if the resulting index fits within the 3x3 game board grid `[0,2]`. Clicks outside the visual game area, especially negative coordinates or coordinates significantly exceeding the board's dimensions, result in out-of-bounds `IndexError` exceptions or unwanted logical behavior due to Python's negative index wrapping. An attacker can repeatedly trigger out of bound clicks.
**Learning:** GUI interactions that map visual space to backend data structures must validate logical boundaries before processing. Even internal array lookups should defensively validate indices if those indices are calculated from external input, like a user's mouse position. Unvalidated user inputs, including mouse clicks, can lead to application crashes (Denial of Service).
**Prevention:** Always validate calculated indices against array dimensions before accessing or modifying the array, especially if the indices are derived from potentially unbounded external input (like mouse coordinates).
