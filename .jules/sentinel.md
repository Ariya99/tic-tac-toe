## 2026-11-04 - Out of Bounds Array Access via GUI Coordinates
**Vulnerability:** The application lacks bounds checking when mapping GUI user click coordinates to logical array indices in `Tic_Tac_Toe.click`. Clicking outside the main 3x3 board (such as negative coordinates or large coordinate numbers) creates array indices like -1 or > 2. Negative indices bypass Python's typical out-of-bounds error and silently access the array from the end, corrupting logical state, while large positive indices cause an unhandled `IndexError` that can crash the application (Denial of Service).
**Learning:** In Python/NumPy, negative array indices wrap around to the end of the structure rather than throwing an IndexError. When mapping GUI coordinates to arrays, indices must be strictly validated to be >= 0 and within array length limits to prevent logical out-of-bounds access.
**Prevention:** Always validate that logically calculated index positions derived from untrusted user inputs (like GUI events) fall completely within the exact boundaries of the target structure `(0 <= index < len)` before attempting access.
