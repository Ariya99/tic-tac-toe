## 2024-05-18 - Out-of-bounds Array Access DoS in Tkinter Map
**Vulnerability:** A lack of boundary validation on logically converted user click coordinates before indexing into a NumPy array allows for out-of-bounds access. Negative coordinates silently wrap around and modify unintended board state, while large positive coordinates trigger an unhandled `IndexError` that can crash the application (Denial of Service).
**Learning:** Translating GUI coordinate systems (like Tkinter Canvas clicks) to backing data structures (like 2D arrays) inherently trusts that the input falls within the visually defined grid. Even with an `is_grid_occupied()` check, the bounds of the array must be validated first. Negative values in Python/NumPy act as reverse index operators, making this a logical overwrite vulnerability as well.
**Prevention:** Always perform explicit bounds validation (e.g., `0 <= x < WIDTH and 0 <= y < HEIGHT`) immediately after translating GUI coordinates to logical array indices and before performing any data structure access or mutation.
