## 2024-10-24 - Missing Boundary Validation in GUI Coordinate Mapping
**Vulnerability:** The application converts Tkinter Canvas grid click events (pixels) to logical board positions (array indices). Because user clicks can occur slightly outside the intended area or generate negative logical indices (which in Python wrap around to the end of an array), this resulted in out-of-bounds `IndexError` exceptions or logically incorrect wrapping, potentially causing a Denial of Service via application crashes.
**Learning:** External user inputs (even via GUI events) mapped to data structures must have their limits explicitly validated. In Python/NumPy, negative indices do not error out but wrap around, causing silent logical failures which are easily exploitable or triggerable by accident.
**Prevention:** Always implement explicit boundary condition checking (`0 <= index < size`) on coordinates before using them to access multi-dimensional arrays or lists, especially when mapping raw event coordinates to logical domains.
