## 2024-03-24 - Out-of-bounds Array Access in GUI Coordinate Mapping
**Vulnerability:** GUI coordinates from Tkinter events (like user clicks) are translated into logical indices (by dividing by board size) without validation, which allows users to click outside the board area (e.g. padding/margins) and pass out-of-bounds indices to the numpy array, potentially causing IndexError exceptions (DoS risk via app crash) or unintentional logical operations if indices are negative (wrapping around the array).
**Learning:** When mapping user-controlled graphical coordinates to internal logic or array indices, standard boundary constraints must always be applied before data access. GUI event bounds are not guaranteed to exactly match the target logical domains.
**Prevention:** Always validate calculated indices against array bounds (e.g. `0 <= index < max`) immediately before using them to access multi-dimensional arrays, preventing crashes and unintended data modifications.
