## 2024-10-14 - Coordinate Calculations in Tkinter Games
**Learning:** While using native Python tuples instead of NumPy arrays is measurably faster (10x) for simple 2D coordinate calculations, applying this to a user click handler in a simple local game is a premature micro-optimization. The "cold path" of a user click doesn't benefit from this speedup in any perceptible way, making the optimization technically correct but practically useless. Additionally, always ensure `__pycache__` artifacts are not tracked in git by using `.gitignore` properly.
**Action:** Before optimizing, verify if the bottleneck is actually in a "hot path" (e.g., rendering loop, large data processing). If the optimization is on a "cold path" (like a button click), avoid making it. Also, always ensure `.pyc` files are explicitly ignored and untracked before submitting.
